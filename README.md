# AI Lead Qualification Agent

A Python-based AI agent that evaluates B2B sales inquiries and automatically classifies them as **HOT**, **WARM**, or **COLD** based on urgency, scale, and intent. 

### Tech Stack
* Python
* Groq API
* Llama 3.1 (8b-instant)

### How to Run
1. Clone this repository.
2. Install dependencies: `pip install groq`
3. Add your free Groq API key to `agent.py`.
4. Run the script: `python agent.py`
